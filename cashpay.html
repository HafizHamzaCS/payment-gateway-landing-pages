The problem

CashPay is how Yemen pays online. WooCommerce just didn't know it.

Tamkeen's CashPay network reaches customers across Yemen — but there's no ready-made WooCommerce plugin for it. Stores lose sales to cash-on-delivery or manual transfers. This gateway puts CashPay's OTP-secured checkout directly on your store.

How it works

Phone number. SMS code. Paid.

1

Customer chooses CashPay

At checkout they pick CashPay and enter their phone number. Works for guests, no account needed.

2

Enters the SMS code

CashPay sends a one-time code; the customer enters it right on the checkout page.

3

Order marked paid

The payment confirms and WooCommerce marks the order paid automatically. You ship.

Security

OTP you can actually trust.

TLS always on

Every call to the CashPay API runs over verified HTTPS — certificate verification is never disabled.

Rate-limited OTP endpoints

Code sends are throttled against SMS spam; verification attempts are throttled against brute force.

Secrets stay secret

API credentials use password-type fields and never appear in logs — nothing sensitive is written to disk.

Verified amount = charged amount

The OTP session is bound to the cart total and re-validated at payment time, blocking amount-swap tricks.
